Внутренний инструмент массового импорта контента в WordPress.

== Description ==

Site Builder — это плагин для автоматического развертывания WordPress-сайтов из подготовленных архивов контента. Поддерживает два режима:

* **Создание сайта** — полный импорт сайта с нуля, включая главную страницу, подвал, стили и структуру вложенных страниц.
* **Добавление страниц** — расширение уже работающего сайта дополнительными статьями.

В обоих режимах поддерживается отложенная публикация: можно опубликовать всё сразу, по странице в день, либо растянуть публикации на заданный период.

Любой импорт можно полностью откатить — плагин хранит точку отката последнего запуска.

== Installation ==

1. В админке WordPress откройте «Плагины → Добавить новый → Загрузить плагин».
2. Выберите ZIP-файл плагина и нажмите «Установить сейчас».
3. После установки нажмите «Активировать».
4. В сайдбаре админки появится пункт меню «Site Builder».
